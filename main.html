Настройка VPN

Выберите свою операционную систему

🤖 Android

Шаг 1. Скачайте приложение v2rayNG

Скачайте приложение v2rayNG

Шаг 2. Установите приложение

Откройте скачанный APK-файл и нажмите кнопку «Установить».

На некоторых устройствах Android может потребоваться разрешить установку приложений из неизвестных источников.

Шаг 3. Скопируйте свою ссылку

Скопируйте ссылку, которую вам прислали в сообщении.

Обычно она выглядит примерно так:

https://example.com/sub/xxxxxxxxxxxx

Вместо звёздочек или символов у каждого пользователя будет своя уникальная ссылка.

Шаг 4. Импортируйте ссылку в приложение

После установки откройте приложение v2rayNG.

В верхней части экрана нажмите на значок «+» и выберите пункт:

Импорт из буфера обмена

Приложение автоматически распознает и импортирует вашу ссылку.

Шаг 5. Удалите лишнюю группу Default

После импорта в верхней части экрана появится жёлтая полоска загрузки, а затем в списке появятся две группы:

  • Default
  • import sub

Чтобы в будущем лишняя группа не мешала, рекомендуется удалить Default.

Для этого:

  1. Нажмите кнопку с тремя полосками в левом верхнем углу
  2. Откройте раздел «Группы»
  3. Найдите группу Default
  4. Нажмите на значок корзины справа

После этого вернитесь назад с помощью стрелки в верхнем левом углу.

Шаг 6. Настройте обход приложений

Чтобы снизить вероятность блокировки VPN, рекомендуется ограничить использование VPN для всех российских приложений и сервисов.

Для этого:

  1. Откройте меню с тремя полосками
  2. Выберите пункт «Выбор приложений»
  3. Включите переключатели:
    • «Использовать выбор приложений»
    • «Режим обхода»

После загрузки списка приложений рекомендуется отметить:

  • банковские приложения
  • приложения мобильных операторов
  • Госуслуги
  • WB / Ozon
  • Все приложения Яндекса и другие крупные российские сервисы
  • И т.д и т.п

Также рекомендуется отключать VPN перед посещением некоторых российских сайтов, если они работают нестабильно при активном VPN-соединении.

Шаг 7. Подключение к VPN

Вернитесь на главный экран приложения.

Для запуска VPN нажмите кнопку Play в правом нижнем углу.

После запуска должны появиться сообщения:

Запуск служб

и затем:

Start Services Success

После подключения нажмите:

Соединено, нажмите для проверки

Если всё работает корректно, появится сообщение примерно такого вида:

Успешно: соединение заняло *** мс
(**) ***.***.***.***

Как отключить VPN

Чтобы отключить VPN:

  • нажмите оранжевую кнопку с квадратом в правом нижнем углу
  • или откройте шторку уведомлений и нажмите:
    • «Остановить»
    • или «Перезапуск службы»
